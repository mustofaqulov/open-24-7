# Redesign artwork

The new photographs are illustrative AI-generated assets, not photographs of
verified business listings. They are used as decorative editorial imagery.
No property inventory, reviews, business facts or prices were invented.

Generated with the built-in `image_gen` tool and encoded as WebP with Sharp
(quality 86, no composition changes). The project has no external image host
dependency for these assets.

- `public/images/redesign/neighborhood.webp`: hero, about, editorial sections.
- `public/images/redesign/cafe.webp`: category invitation, business, authentication,
