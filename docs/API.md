# Open24 API v1

All responses are JSON. Errors use `{ "error": { "message": "..." } }`; validation errors also contain `issues`. Invalid input returns 400, missing authentication 401, forbidden operations 403, missing records 404, conflicting review decisions 409, rate limits 429, and unavailable dependencies 503. State changing requests require a same-origin `Origin` header. Cookie sessions are HTTP-only. API responses use `Cache-Control: no-store`.

Coordinates are WGS84 latitude and longitude. Search and route origins are sent in POST bodies rather than page URLs. The server does not store search or route origins.

Search radius is 0.5–50 km (default 10), page is 1–100, and limit is 1–30 (default 12). `openNow` and `alwaysOpen` are the strings `"true"` or `"false"`. Search returns only verified businesses. The optional `q` value matches the business name, address and city, and also the category name in any stored locale, so a query such as `do'kon`, `magazin` or `supermarket` returns shops. `openNow` includes only calculated `OPEN` results. The API examines the 1,000 closest matching records within the radius; `truncated:true` means the caller must narrow the query for complete results. Search distance is **straight line** metres. Route distance and travel duration appear only in the separate route response.

Weekly hours use Sunday = 0 and minutes after midnight 0–1440. A close minute earlier than or equal to the opening minute denotes an overnight interval. All seven weekdays must have an explicit schedule, including closed-day rows, or status is `UNKNOWN`. Date-specific exceptions use the business's local calendar date and override the weekly schedule for that date. An explicit closed exception also cancels overnight carryover. Seven 00:00–24:00 rows denote 24/7 only when no current or future exception changes that schedule. `UNKNOWN` includes incomplete, OSM sourced, and stale hours. An owner name or address change returns a business to moderation.

Password reset, email verification, full OpenAPI generation, and pagination for admin lists remain release tasks.
